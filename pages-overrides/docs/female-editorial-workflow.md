## 6｜工作台接入

现场手动：附有权使用的参考图 → 复制提示词 → 在可用生图工具生成 → 人工 QA → 保存合格输出。国内模型需根据实际支持的参考图数量拆步，不假定同样的商品保真率。

自动化：浏览器提交任务描述，本机服务端从外部凭证或环境变量取密钥，调用 MiniMax V2，轮询真实任务，保存真实视频；前端显示真实状态。密钥不能进入 HTML、JS、下载包或浏览器存储。无 API 时可复制提示词、下载任务清单、导入本地视频预览。

参考视频经本地抽帧完整观看，其素材拆解方式可见；作者使用的确切模型、提示词和生成次数无法确认。桌面的人像摄影提示词 Skill 仅供光线和皮肤质感参考；五人拼贴的换装视频 Skill 不适合这套单人杂志短片。
