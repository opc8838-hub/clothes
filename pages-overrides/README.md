# 一件衣服，一段生活 · 虎门服装 AI

15 页可交互演讲站。保留暖石色杂志视觉、人物与服装图组、真实视频、男生白/黑 T 案例和原衣服展厅。

## 本机打开

1. 解压完整 ZIP。
2. 安装 Node.js 18 或更新版本（已安装可跳过）。
3. Windows 双击 `打开网站.cmd`；浏览器会自动打开，演示时保留服务窗口。

其他系统：在解压目录运行 `node tools/serve-site.mjs --open`。

默认地址：http://127.0.0.1:8787/ 。端口已被当前站点占用时直接访问该地址；需要不同端口时配置 PORT 环境变量。

完整使用说明见 `guide.html`。直接用 file:// 打开 HTML，浏览器会限制素材探测与 JSON 加载，因此请使用本地服务。

## 交互

方向键 / PageUp / PageDown 翻页；Home / End 首末页；N 备注；F 全屏；Esc 关闭弹窗。目录、章节导航与浏览器前进/返回可用。长页支持滚动，手机上可用“本页还有内容”继续浏览。

图片可放大并查看站内参考输入。任务、场景、弹窗和分镜提示词均可编辑、复制与下载；本次会话中保留手改内容，明确点击重建或恢复默认才覆盖。刷新或关闭页面前请下载需要保留的草稿。

上传图片、视频只在当前浏览器内准备输入或预览，不自动提交模型。替换换装输入后会将旧结果标为待重新生成，支持恢复示例。九镜可切换成片、首帧、尾帧；本地导入的视频可移除，不计入 API 生成数量。

收尾页支持下载完整站点、当前提示词与素材清单，以及原演练包。解压后的离线站点不嵌套另一个同名网站 ZIP，该下载入口会显示“当前为离线站点副本”，其他资料仍可使用。

## 文件

- `index.html`、`css/`、`js/`、`data/`：主站与交互。
- `guide.html`：面向观众的使用说明。
- `assets/fashion/female/`：女装图片、视频与同名生成记录。
- `male-case/`：原男生完整案例。
- `wardrobe/`：既有展厅，27 个文件与重构前哈希基线一致。
- `docs/female-editorial-workflow.md`：女装演练方法。
- `tools/serve-site.mjs`：仅监听本机的静态服务，支持视频 Range 请求和下载流式读取。
- `tools/package_site.py`：按明确白名单打包。

## 验证与打包

JS 语法检查：`node --check js/site.js`、`node --check js/gallery.js`、`node --check js/finish.js`。

重新打包：`python tools/package_site.py`，生成 `deliverables/humen-fashion-talk-site.zip`。

本机 QA 脚本与证据保存在 `output/qa/completion/`。输出目录与服务端凭证不进入网站包。动效来源与许可保存在 `licenses/`。
